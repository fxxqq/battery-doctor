电池医生 Windows 版 · 使用说明
================================================

一、这是什么
------------------------------------------------
一个不用安装、打开就能用的 Windows 体检小工具。它做的事很具体：

  · 每 5 秒记录一次电池电量、电流、电压、温度，掉电断过一次就留一份证据
  · 读 Windows 事件日志里的「异常关机」（事件 41 / 6008）——这是判断
    「电脑用一会儿就自己关掉」最直接的证据
  · 读官方电池报告，算出电池健康度和循环次数
  · 列进程、存储占用、开机启动项，可以一键清理临时文件、禁用启动项
  · 网络诊断 + 一键修复（重置代理、DNS、清缓存、重取 IP、重启网卡）
  · 一键体检：跑完给一句人话结论，并生成报告存到桌面


二、怎么用（两种方式，任选一种）
------------------------------------------------
【方式 A：直接跑，不打包】

  1. 装 Python 3.9 或更高版本：https://www.python.org/downloads/
     安装时记得勾选 "Add python.exe to PATH"
  2. 双击  「直接运行.bat」
  3. 稍等 2 秒，程序窗口就出来了

  这种方式适合你想改代码、或者懒得等打包。


【方式 B：一键打包成 exe（推荐，给别人用就选这个）】

  1. 装 Python（同上，只需装一次）
  2. 双击  「一键打包.bat」
  3. 等 1~3 分钟，脚本会自动装好 PyInstaller 并打包
  4. 成品在  dist\BatteryDoctor.exe

  这个 exe 是单文件，可以单独拷到任何 Windows 10/11 电脑上双击运行，
  对方不需要装 Python，也不需要装任何运行库。


三、几个要注意的点
------------------------------------------------
1) Mac 上不能直接生成 exe
   PyInstaller 不支持交叉编译——在 Mac 上打包出来的永远是 Mac 程序。
   要得到 exe，必须在 Windows 机器上跑一次「一键打包.bat」。

2) 有些功能要管理员权限
   重置 DNS、重启网卡、改系统级设置都需要。程序左下角有
   「以管理员重启」按钮；不是管理员时，相关步骤会标黄并说明原因，
   其余功能照常可用。

3) 数据存在哪
   %LOCALAPPDATA%\PowerWatch\
     power.csv        每 5 秒一条的采样记录
     incidents.log    疑似断电记录
     app.log          运行日志（出问题看这个）
     crash.log        万一闪退，堆栈在这里

4) 第一次打开被 Windows 拦了
   SmartScreen 会提示「未知发布者」——点「更多信息」→「仍要运行」。
   自己打包的 exe 没有代码签名，这是正常现象。

5) 台式机
   没有电池时会显示「没有可读的电池」，其余（进程、存储、启动项、
   网络、关机记录）都能正常用。


四、文件说明
------------------------------------------------
  main.py           入口
  bd_core.py        数据层：WMI / powercfg / 事件日志 / netsh / 注册表
  bd_ui.py          界面层：6 个页面 + 一键体检 + 网络修复
  icon.ico          程序图标
  一键打包.bat      打包成单文件 exe
  直接运行.bat      不打包，直接运行
  使用说明.txt      本文件
